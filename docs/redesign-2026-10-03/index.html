zzThis home page: three redesign samples

A Hallmark audit of the live site, ten 2026 design techniques, and three directions built from the repo's own images and the spec's verbatim copy. Static prototypes for review: they live under docs/ and never deploy.

Full audit, research, and sources: README.md in this folder.

A · Tape

Structure
Narrative Workflow: Mark 1.0 → Read 2.0 → Link 3.0 → Report 4.0, with the code's state shown at each stage
Look
Cream paper, painter's tape, marker hand; Bricolage Grotesque + Shantell Sans + Plex Mono
2026 moves
Hand-made marks, real photos, variable handwriting axes, scroll-drawn line
Best for
Everyone: explains the idea at a glance

B · Resolver

Structure
Workbench: the hero runs the live demo's parser and exact-match resolver on mock data
Look
Dark instrument panel, blueprint grid; the current IBM Plex family
2026 moves
Working demo in the hero, View Transitions, anchor positioning, dithered "machine view"
Best for
xTechSearch reviewers, engineers, logistics buyers

C · Hi-Vis Manifesto

Structure
Manifesto: one claim per block, charcoal and cream slabs
Look
Archivo on its width axis, safety orange, greyscale panels, one colour photograph
2026 moves
Kinetic variable type, CSS subgrid comparison, scroll-driven sweep, restraint
Best for
Investors and the brand: the most memorable

Before any of it goes into the repo

Pick a direction or a mix (A's tape and real photos with B's console works well). Michael approves the few new lines each sample adds. Fonts move to self-hosted @fontsource packages. Then the repo's process applies: an intent file a person accepts, a spec 001 update, and a PR for Danny.

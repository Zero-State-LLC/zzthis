### Current implementation status (2026-10-07)

The isolated implementation branch contains the schema/hash/relationship preflight and pinned decoder replay described above, plus an integrated diagnostic scoring pipeline for fiducial/pair, exact-code/part-word/CER/false-valid, ROI/rectification/latency, band, wrapped/multi-code, no-code, crash/exception, and runtime-memory observations. These score by split, device, and stress bucket; final-only evaluation computes the eight frozen numeric gates, including maximum per-device p95. The adapter-result schema requires explicit runtime outcomes and accepts per-observation peak-memory evidence; failed runtime rows cannot include recognition output and are kept out of decision-band metrics rather than assigned a fabricated band. The scoring projection emits receipt-shaped metric sets and device coverage; package-size delta remains explicitly unmeasured until its baseline is frozen. On 2026-10-08, preflight integration was extended to assemble a hash-addressed receipt and privacy-minimized Markdown report after successful diagnostic scoring. The artifact is schema/semantics validated but always explicitly `INCOMPLETE`, with no promotion fields or authority; missing trusted freeze time and all unavailable reviewers/case dispositions are represented as blocked/unassigned rather than inferred. CLI stdout exposes only aggregate scoring and a receipt hash/status summary; per-sample OCR/case evidence is emitted only to an explicit mode-0600 output file. On 2026-10-08, all 89 OCR qualification tests across 15 files passed, and repository lint, typecheck, and build passed; Wrangler emitted a non-fatal user-log permission warning in this sandbox.
